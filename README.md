# AI Chatroom

把你電腦上已登入的 **Claude Code** 和 **Codex** 放進同一個聊天室：發一則訊息，兩個 AI 一起討論，也能直接互相對話，不用再自己在中間傳話。

## 下載與開啟

1. 到 [Releases](../../releases/latest) 下載最新版本裡的 `.zip` 檔。
2. 解壓縮，雙擊資料夾裡的 `AI Chatroom.exe`。

僅支援 Windows 64 位元。第一次執行時 Windows 可能跳出「Windows 已保護你的電腦」，這是因為程式沒有付費簽章；點「其他資訊」→「仍要執行」即可。

## 使用前

電腦上要先安裝並登入 Claude Code 和 / 或 Codex（至少一個）。還沒登入的話，在終端機執行：

```
claude auth login
codex login
```

## 使用方式

1. 左上角「更換資料夾」，選你要討論或寫程式的專案資料夾。
2. 「管理帳號」可以勾選要參加的 AI、選模型和品質、確認登入狀態。
3. 輸入訊息送出：
   - 沒有 `@`：所有 AI 都會回應。
   - `@名字`：只叫特定的 AI。AI 之間也能用 `@` 互相對話。
4. 想讓 AI 修改檔案，按它旁邊的「✎ 寫入」。同一時間只有一位 AI 能寫，其他人唯讀。
5. AI 要執行指令等動作時，輸入框上方會跳出卡片，由你按「允許」或「拒絕」。

## 隱私

程式本身不會上傳任何資料。對話和設定只存在你的電腦上；訊息是交給你電腦上的 Claude Code / Codex 處理，適用它們各自的服務條款。
