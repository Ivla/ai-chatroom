# AI Chatroom

把你電腦上已登入的 **Claude Code**、**Codex** 和 **Antigravity（Gemini）** 放進同一個聊天室：發一則訊息，AI 們一起討論，也能直接互相對話，不用再自己在中間傳話。

可以開很多個對話，每個對話各自決定哪些 AI 參加、用哪個專案資料夾。

## 下載與開啟

1. 到 [Releases](../../releases/latest) 下載最新版本裡的 `.zip` 檔。
2. 解壓縮，雙擊資料夾裡的 `AI Chatroom.exe`。

僅支援 Windows 64 位元。第一次執行時 Windows 可能跳出「Windows 已保護你的電腦」，這是因為程式沒有付費簽章；點「其他資訊」→「仍要執行」即可。

**自動更新**：0.3.0 起，程式會定時到這裡檢查有沒有新版，有的話自動下載（會先核對 SHA-256），在你關閉程式時換成新版；左側的「更新」區可以手動檢查、馬上重新啟動更新，或關掉自動更新。需要程式所在的資料夾你有寫入權限（放在桌面、文件、D 槽都可以，放在 Program Files 不行）。

從 0.2.0 或更舊的版本升級：這一次請手動下載 0.3.0，解壓縮後用新的資料夾取代舊的；你的設定和對話紀錄會自動保留。之後就會自動更新。

## 使用前

電腦上要先安裝並登入你想用的 AI（至少一個）。還沒登入的話，在終端機執行：

```
claude auth login
codex login
agy
```

`agy` 第一次執行會要求登入 Google 帳號。

## 使用方式

1. **管理帳號**（左下）：偵測電腦上已安裝的 AI、選模型和品質、確認登入狀態。這裡只管「你有哪些帳號」。
2. **對話**（左上）：「＋ 新對話」新增一個；連按兩下可以改名。每個對話有自己的訊息、專案資料夾和參與者，互不影響，也可以同時在背景繼續工作。
3. **參與者**：這個對話要讓哪些 AI 加入，隨時可以加入，或按 × 移出。例如 A 對話只有 Claude 和 Codex，B 對話三個都參加。
4. **專案資料夾**：按「更換資料夾…」選這個對話要用的資料夾，每個對話可以不一樣。
5. 輸入訊息送出：
   - 沒有 `@`：這個對話裡的 AI 都會回應。
   - `@名字`：只叫特定的 AI。AI 之間也能用 `@` 互相對話。
6. 想讓 AI 修改檔案，按它旁邊的「✎ 寫入」。同一時間只有一位 AI 能寫，其他人唯讀。
7. Claude 和 Codex 要執行指令時，輸入框上方會跳出卡片，由你按「允許」或「拒絕」。Antigravity 只能改檔，不能執行指令。
8. AI 可以上網搜尋（左側「規則」裡可以關掉）：Claude 每次搜尋或讀網頁都會先問你，Codex 直接搜尋，Antigravity 只能搜尋、不能開網頁。
9. AI 回覆裡的 Markdown（標題、粗體、清單、表格、程式碼、連結）會排成正常的樣子。

## 隱私

程式不會上傳你的對話或設定，這些只存在你的電腦上；訊息是交給你電腦上的 Claude Code、Codex、Antigravity 處理，適用它們各自的服務條款。程式唯一會主動連的地方是 GitHub：匿名查詢這個專案的最新版本，並下載新版；不想要的話，把左側「更新」裡的「自動檢查並更新」關掉就不會再連。
